# 阶段 2 数据准备 — "水电接通"操作手册

> 目标：拿到 2 把"钥匙"（API Key），覆盖 3 类服务（AI 大脑 / 地图 / 天气），并逐一调通。
> 你的任务：注册 2 个开发者账号（约 10 分钟，只需点击和手机验证码）。
> 我的任务：拿到钥匙后写入安全文件、逐项跑测试、全绿后打 v0.3 书签。

---

## 钥匙是什么（大白话）

API Key（钥匙）= 一串字母数字组成的"通行证"。你调用外部服务时出示它，对方就知道是你、给你记账。**免费额度内不花钱**：智谱 GLM-4-Flash 有免费额度，高德个人开发者每天几千次查询，本项目完全够用。

安全规矩：钥匙只存本地 `.env` 文件（已被 .gitignore 挡住，永不上传 Git）。万一泄露，在平台后台可以一键作废重建，损失为零。

---

## 钥匙 1：智谱 GLM（AI 大脑）

1. 打开官网：**https://open.bigmodel.cn**（智谱开放平台）
2. 点右上角「注册 / 登录」→ 手机号 + 验证码（或微信扫码）
3. 登录后，进入 API 密钥页面：**https://open.bigmodel.cn/usercenter/apikeys**（或右上角头像 → 「API 密钥」）
4. 点「新增 API Key」→ 名字随便填（如"行程规划"）→ 生成后点「复制」
5. 把这串字符发到我们的对话里，我来处理

**你会拿到**：一串类似 `abc12345.xyz67890` 的字符（约 30 位）。

## 钥匙 2：高德开放平台（地图 + 天气，一把顶两用）

1. 打开官网：**https://lbs.amap.com**（高德开放平台）
2. 点右上角「注册 / 登录」→ 手机号验证
3. 首次使用需**个人开发者认证**（平台规定，免费）：按提示用支付宝扫脸即可，几分钟完成
4. 进控制台 → 「应用管理」→「我的应用」→ 点「创建新应用」：
   - 应用名称：`行程规划`（随便填）
   - 类型：选「出行」
5. 在刚建的应用里点「添加 Key」：
   - Key 名称：`行程规划-web`
   - 服务平台：**必须选「Web 服务」**（注意：不是"Web端(JS API)"，那个是另一类，别选错）
6. 生成后点「复制」

**你会拿到**：一串 32 位的字符（字母数字混合）。

> 为什么选"Web 服务"：它负责后端查询（搜地点、算路线、查天气），是我们后端服务器用的；"JS API"是网页里画地图用的，到阶段 5 做前端地图时可能再补一个，到时再说。

## 天气不用单独注册

高德的 Web 服务 Key 自带天气查询接口，一把钥匙两用，省钱省事。

## 拿到钥匙后我会做什么（你不用动）

1. 写入本地 `.env` 文件（加密规矩已生效，永不上传）
2. 跑 3 条测试命令逐项验证：
   - [ ] 智谱：发一句话，AI 能回话
   - [ ] 高德地图：查"成都宽窄巷子"的位置 + 到"锦里"的路线
   - [ ] 高德天气：查成都未来几天天气
3. 三项全绿 → 提交存档 → 打 **v0.3「水电接通」** 书签
4. 任何一项失败：我排查原因（常见是 Key 选错类型、复制时带了空格），修好再验，不带你纠结

## 常见坑位提示（遇到就对照）

| 现象 | 原因 | 解法 |
|---|---|---|
| 高德报 `INVALID_USER_SCODE` | Key 类型选错（选成了 JS API） | 删掉重建，选「Web 服务」 |
| 智谱报 `401` | 钥匙复制不完整或带了空格 | 重新复制粘贴 |
| 实名认证卡住 | 网络或支付宝授权问题 | 换浏览器重试，或先跳过（部分接口不认证也能建 Key，能建就行） |
