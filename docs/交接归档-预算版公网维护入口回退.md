## 停止点与恢复

2026-11-19 后续只读检查发现，Windows 到原机的默认路由走 FlClash。默认路由与单独绑定 WLAN 的连接均能访问原 HTTP 旅行入口并收到 200。443 关闭时，默认路径走到 TLS 超时，WLAN 路径在 TCP 阶段超时。这些数据反映本机两种观测路径，首次发布时的超时原因仍未知。[观测回执](verification/budget-public-maintenance-route-recheck-preflight-2026-11-19.json) · [Windows socket 网卡选项](https://learn.microsoft.com/en-us/windows/win32/winsock/ipproto-ip-socket-options)
