## 2026-09-09 深夜 · v1.0.1 热修：AI 行程"空天数"断链（用户浏览器验收抓到）

【现象】/plan 页输入"去杭州玩 2 天"→ 显示"行程已生成（2 天）"，但右侧 第1天/第2天
全是空卡片，核实报告 0 条，过程日志显示"地图核实：0 个地点过检"，也没有总览地图。

【根因 1（主犯）· M2→M3 字段契约断裂】
