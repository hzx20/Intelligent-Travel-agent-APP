## 实际Linux通过项

1. **维护原字节语法**：在现役容器0700内存目录保持4f0…候选字节不变，使用原mime.types链接执行nginx-t退出0，副本删除并复核不存在。未向现役master发信号。

3. **保留inode维护切换**：仅重建自建容器的挂载基线后，原inode写入维护字节，双侧哈希一致、完整检查及reload通过；7种方法×6类旅行路径的 **42组合** 均503/no-store/Retry-After=60，合成另一站点根首页仍200。
4. **坏配置拦截和恢复**：语法错误候选完整检查非0，守卫拒绝reload，原内存维护响应继续服务；通过同一描述符恢复保存字节，检查恢复为0。
5. **不可绑定地址拦截**：本镜像nginx-t对192.0.2.123的监听先输出syntax is ok，随后bind失败并最终退出1。守卫按完整退出状态拦截，不能只读第一行。未放宽为通过，也未发送该候选reload。
