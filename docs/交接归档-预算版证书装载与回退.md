# 独立 nginx 证书装载与回退验收

2026-11-19 后续已完成首次装载与续期接入的本机验收。以下保留同镜像合成换代与回退的原始结论。[首次装载与续期接入](交接归档-预算版首次装载与续期接入.md)

2026-11-19，Asia/Shanghai。独立代理的证书换代和故障回退通过原服务器同 nginx 镜像隔离验证。本轮未签发正式证书、未开放 443、未重载或改变任何线上服务。

- 新增 `backend/tools/travel_tls_rotate.py`。在受限目录内分别保存各代证书与私钥，通过锁和原子指针更新选择同一代，禁止用同一叶证书指纹覆盖不同的链或密钥。换代前先用 TLS 确认当前实际送出的叶证书，验证新链和密钥匹配，切换后先 `nginx -t`、再加载，最后比对两次 TLS 握手中的证书指纹。无法确认旧证书或回退时返回失败，不能继续开放。
- 原服务器临时容器使用现役 nginx 同一镜像，网络关闭、无发布端口、挂载唯一自建的私有工作目录且只读。合成 CA、证书和密钥全部在原服务器临时目录生成，未读取现网密钥，证书未导出。实测新证书确实送出、同代再次提交不加载、私钥不匹配被拒绝、配置语法失败恢复指针且不加载。最后故意在新证书已实际送出后判为验收失败，恢复上一代并重新用握手确认。总共只向自建 nginx 发送三次加载信号。
- 首两轮因 Docker 缺失提示大小写识别失败未通过，分别只读确认两轮自建容器及工作目录均已消失。修正识别后第三轮通过且回执确认清理。其后另补本机测试，验证加载命令超时时（即使信号可能已到达）也恢复旧证书，未重新在 Linux 测这个额外异常分支。4 项本机定向测试通过，保留两版源文件哈希。
- 独立正式代理的正常和维护审阅件仅把证书路径改为 `/etc/nginx/travel-tls/current/{fullchain,privkey}.pem`，旧审阅件未覆盖。正式挂载应绑定证书**父目录**，不能绑定当前符号链接或两个文件的 inode。ACME 账号目录也不挂入代理。

[机器回执](verification/budget-ip-tls-rotation-2026-11-19.json)保留隔离结果、两个失败尝试、正式审阅件哈希与本机超时补测。成功原始回执 `.release-candidates/budget-https-load-2026-11-19/rotation-32a8e1d79b6ac354.jsonl`，SHA256 `2ae7432015177668f98fbd5f3d7a0d8ff5328d2980f7329e6a7b6269ccb654f9`。当前审阅件位于 `.release-candidates/budget-https-load-2026-11-19/https-ip-edge-rotation-review/`。在 `backend` 内运行 `python -B -m pytest tests/test_travel_tls_rotate.py -q` 可复验本机流程；私有 `run_tls_rotation.py` 默认只核对本机输入，无需重复连接原机。

## 停止点和后续

本轮在独立代理的合成换代通过后停止。下一步为明确实际部署的独立容器身份、入口、证书目录权限及告警接收人，审阅正式签发窗口，验证首次装载和生产续期钩子。首次装载没有已知上一代，须独立核对并保持维护，不能使用轮换的“可信上一代”前提。验收续期钩子前不要启用[续期审阅件](交接归档-预算版正式证书与续期审阅.md)。进程意外终止、重新握手失败或送出证书与磁盘指针不符时，不盲目再加载或删除上一代；证据未确认则保留维护与告警。真实账号设备、8000 入站限制、正式留存备份及切换仍待验收，`production_ready=false`。
