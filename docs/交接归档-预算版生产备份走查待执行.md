控制器先在私有审阅目录独占创建 `production-attempt.jsonl`，再连接 SSH。一轮只发一次：再次运行会在连接前拒绝。只有退出码、候选版本、原数据比对、权限与清理证据全部齐备才归档通过；不保存原始 stderr 或不合规输出。SSH 超时、回执缺失或仅有 `starting` 均按未确认处理，先根据尝试标识核对确切进程与隔离挂载是否退出，不覆写回执或触发重跑。9 项本机测试覆盖回执缺项、载荷漂移、错误数据拒绝归档和超时不重复提交；本轮未连接 SSH 或创建生产尝试回执。

受保护演练副本会删除，不能充当正式备份。正式切换前需指定受限保留位置和恢复负责人，确认加密备份在原机不可用时仍可取得，且恢复用密钥的保管与备份分开。不得把密钥值或库写进本仓库、发布候选或公开报告。

| 恢复物 | 验收条件 |
| --- | --- |
| SQLite 及真实附件 | 写入停止后生成正式快照，记录版本、时间、大小、校验值和权限。足迹照片随库恢复；攻略、头像和地点图片如果含本地引用，逐一确认所需实际附件，不用外链是否能访问代替备份检查。 |

| 可恢复性与停机预算 | 从正式保存位置独立取回并恢复到新数据目录，由值守人核对 SHA256、完整性、外键、旧数据查询和访问权限，记录取回、恢复和验证的总时间，以及快照之后可能损失的数据范围。本次内存演练耗时不能作为正式恢复时间承诺。 |
