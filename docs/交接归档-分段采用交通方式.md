# 分段采用交通方式交接

2026-11-18，Asia/Shanghai。本轮完成在旅行里为每个相邻地点分别选择步行或驾车，以及按已选择方式核对步行量、安排间隔和地图路线。整体目标仍在进行。

在「行程 → 地点间交通」中逐段选择或清除方式。「查询 / 重试交通」比较同一方式，「查询已采用路线」只查已选且尚无有效结果的段。同一段切换方式只采用对应结果。比较结果不影响日程提示。已采用的小计保留总段数；未选择、地点不明、查询失败和已过期的路段仍待核对。仅部分路段的已知步行量超上限时仍提示超限。场馆内、停车及上下车接驳步行另计。

无地点的休息仍是日程安排。计算交通空档时，在已知休息的起止时间之外取最长连续空档；缺少休息时长或时间时不猜测。地图在采用方式后以已查到的对应路径画实线，其他段只保留顺序示意。刷新后记住采用方式，路线耗时需要主动复查。真实地图 JS 在本轮使用替身，路径取自已录制的高德数据。

账号旅行和本机旅行均按版本保护保存。选择绑定有方向的相邻地点及当时坐标和高德地点标识；更换地点或手动、AI 改变连接顺序会撤销受影响的选择。调整开始时间不改变连接时保留选择。旧 SQLite 由启动迁移补 `trip_days.route_preferences` 空对象。访客复制快照按当天安排位置保留方式，服务端用新项目 ID 重建连接；旧服务明确不支持时阻止会丢字段的复制。无新字段的旧快照保留原摘要语义。
