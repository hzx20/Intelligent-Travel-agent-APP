# 具体地点与馆区匹配交接

2026-11-18，Asia/Shanghai。本轮完成复杂规划的地点身份检查及候选展示。整体改造目标保持进行中。

## 已完成

原规划器比较同城地点名称、正式景区后缀和高德地点 ID。只在当前候选中能唯一匹配时设置地图坐标。可区分馆区的括号、连字符等格式差异先标准化，馆名和分馆名保留区分。高德每个明确名称最多查询一页20条，同一规划内重复名称复用结果。未指定的机构名可同时对照本地库和高德，候选只表示当前检索结果。

名称含糊、出现多个馆区或未找到具体地点时，保留原安排、时间和估算金额。未确认项清除候选以外的旧位置、地址和接驳展示。页面最多列出五个供核对的候选，包含名称和地址或区域。候选列表只读，地图、导航和住宿匹配使用已确认的位置。原历史方案里的“已替换”标记仍可读取。
