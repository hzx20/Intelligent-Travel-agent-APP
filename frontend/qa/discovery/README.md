## 行为边界

读取保留同账号上次确认内容，错误提示指出旧结果仍显示；筛选摘要绑定已成功条件，新失败查询独立保留供重试。URL只保存已提交的公开检索条件/页数，未搜索输入不持久化。灵感页未提交需求有路由/刷新/换号确认，接受离开或清数据不保证恢复；明确提交才交给原规划的可靠创建协议。替换灵感前确认，示例清旧城市参数，自动组合的天数会跟随新选择。

私人推荐与足迹换号立即清旧结果，旧异步响应按账号/代次/请求顺序隔离；足迹私有照片仍沿用原鉴权请求。服务器权限有变化时需重新读取核对，保留旧数据不表示实时撤权通知。真实设备、实际地图/AI/OCR、外部授权攻略及生产部署仍待完成。最新归档`docs/交接归档-发现页恢复.md`。
