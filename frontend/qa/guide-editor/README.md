# 攻略编辑草稿与提交保护

在frontend目录运行 `npm run test:e2e:guide-editor`。继承真实后端账号夹具，使用临时磁盘库、随机测试JWT和独立Edge；阻止非本机请求。桌面1280×900、手机视口390×844各十五项，共30项；视口验收不等于真实手机。

与accounts/sharing/network/creation共用5264、18963，须串行。Python默认使用工作区上级`.venv-analysis`，其他环境可设置TRAVEL_E2E_PYTHON。测试截图与失败trace在Git忽略的`playwright-results/guide-editor`，可能包含合成凭证，不发布。

## 可重复的页面证据

1. 新攻略离开取消保留标题、正文及未添加图片链接；确认才离开，未发布到云端。
2. 原攻略不修改可直接离开；修改后刷新取消保留输入，确认重载恢复已保存原文。
3. 退出账号取消保留；确认后清除本页内容并显示登录提示。
4. 提交期间禁用字段、图片/景点操作和保存；成功存草稿正常打开个人中心，云端只增加一篇。
5. 编辑读取503时不显示可提交的空编辑器，重新读取成功后恢复原文。
6. 新建已提交后丢响应：保留正文与同次标识，继续找回同一攻略；取消放弃不丢失信息。
7. 编辑已提交后丢响应：继续编辑仍用原版本，再提交拒绝覆盖；核对入口定位原攻略。
8. 编辑成功保持原编号，刷新显示已修改正文。
9. 后端已提交但浏览器收到不完整200时保持待核对，不清表单或再次发布。
10. 明确422拒绝仍保留创建标识；确认放弃后可改正文并生成新尝试，云端只有一篇。
11. 创建响应丢失后刷新恢复同标识，原攻略被另页编辑后继续仍返回当前状态，不覆盖新正文。
12. sessionStorage配额失败时保留输入、不发送创建POST。
13. 写入能力或专用创建路径缺失时不降级旧POST。
14. 云端更新后旧保存409；取消重载保留正文，确认才加载新版本，之后编辑正常成功。
15. 陈旧详情删除409；重载并确认后才删除当前版本。

原生confirm/beforeunload由浏览器真实触发；不覆盖window.confirm。丢响应由先提交真实接口再中断浏览器响应制造，503/422及不完整JSON是受控注入。截图uncertain-guide.png供检查待核对状态的桌面/手机排版。没有使用个人文件、真实账号或外部图片/服务。

## 状态规则与边界

编辑页按加载成功的表单、图片顺序及景点编号建立基线；修改后、未添加图片地址或待核对提交均保护路由离开、复用路由更新、刷新关闭和账号变更。未提交输入不自动保存。已经提交的新建快照及UUID按账号保存于本标签sessionStorage，刷新可继续；成功打开目标页后清除。关闭标签或清除存储后不能保证找回标识；已创建攻略仍可核对云端。表单明确说明保留范围，快照内不存JWT。

加载失败/无权限不允许提交空白表单。保存用独立图片数组快照，忙碌期间锁定交互；旅行之外的攻略编辑也接入同一账号变更注册器。请求代次、账号与路由编号保护读取/保存/搜索，旧页结果不影响新页；搜索序号拒绝乱序候选，失败有提示。

创建按GET `/api/guides/write-capabilities`核对能力，再POST `/api/guides/create`，不降级旧POST。账号+UUID唯一、内容哈希拒绝换内容；攻略/图片/关联景点/创建映射在一个事务里。首次201、重试200返回同攻略当前编号/草稿状态/版本/稳定标识，不覆盖后续内容；原攻略被删除410，旧标识不重建。并发候选发生唯一冲突时回滚并重查，不能留下多余图片。

编辑加载version和revision，PATCH `/{id}/content`携带这两个原值。服务端原子领取版本后才改正文、图片和景点，失败整笔回滚；新版本拒绝旧保存/删除409。稳定revision防止SQLite编号复用把旧编辑指向另一篇；浏览量增长不推进内容版本。详情DELETE使用`/{id}/content?version=...&revision=...`，页面错误保留详情，可明确重载核对。旧PATCH/DELETE也必须提供两项，否则428，不能绕过新保护。

超时/断连/5xx、会话不确定或不完整成功时保留输入。新建只继续原快照，不换标识；任何明确放弃都提示先核对、不删除云端。编辑可明确继续原版本，409不自动升级版本；只有确认重新载入才用云端替换本页输入。编辑输入/未知编辑尝试不跨刷新自动保存；本模块不是所有写入的通用幂等，也不代替生产迁移或实际设备验收。

组件生命周期与上下文测试在`frontend/test/guideEditorComponent.test.js`，八个子场景加父测试计九项；创建存储另三项在`guideCreationAttempt.test.js`。后端`test_guide_writes.py`六项覆盖并发、哈希/账号隔离、实际编号复用及子写入失败回滚，另有磁盘服务重启与旧结构副本升级验收。组件测试不渲染DOM，完整交互以上述端到端为准。
