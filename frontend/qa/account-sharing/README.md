# 真实后端隔离账号与分享验收

在 frontend 目录运行：

```powershell
npm run test:e2e:accounts
```

默认使用已安装的 Edge 和 `C:\Users\i\Desktop\travel\.venv-analysis\Scripts\python.exe` 对应的相对项目路径。其他机器可设置 `TRAVEL_E2E_PYTHON` 为装有 backend/requirements.txt 的 Python；浏览器准备方式同 `../draft-guard/README.md`。

配置启动真实 `app.main:app` Uvicorn（127.0.0.1:18963）和完整 Vite 应用（127.0.0.1:5264/travel/），使用实际鉴权、旅行、分享和预订路由。API代理仅将 `/travel/api` 转发至该后端并去掉 `/travel`；不连接现有8000或生产服务。两个端口必须空闲，不复用未知服务。

后端启动前创建 `travel-browser-accounts-*` 临时目录并设置绝对 TRAVEL_DATA_DIR，生成本轮随机 JWT_SECRET；外部模型和高德钥匙显式置空。前端不加载 .env，浏览器拒绝所有非本机来源请求。注册、登录、创建旅行、邀请及预订均使用合成数据；不调用模型、OCR、地图或真实预订。测试没有模拟登录、权限或写入结果。

桌面1280×900、手机视口390×844各十一项，共22项：

1. 登录弹窗Tab留在对话框内，Esc关闭、焦点归还，重开密码为空。
2. 通过页面注册并自动登录，重载恢复登录态。
3. 游客有草稿时取消登录不发送登录请求；确认后登录、清除草稿、保留本机旅行。
4. 取消退出保留云端草稿；确认退出并登录另一账号后，页面和真实API均拒绝读取原旅行。
5. 两个独立账号上下文接受编辑邀请、修改主题、创建者同步时保留草稿、确认刷新、撤销邀请及移除成员；被撤权页面保留未提交内容，实际保存被拒绝，数据库没有新增安排，撤销链接不能重新加入。
6. 手动预订和公开安排并存时，只读页面与实际响应均不含预订记录/订单号；撤销后重新加载无法读取。
7. 同一浏览器的另一标签换号时，旧页保留草稿并暂停请求；写入尝试不发网络请求，旧页退出不清掉新账号，取消同步保留输入，确认同步后才切换并拒绝旧旅行。
8. 另一标签退出时，取消同步保留云端正文，确认后显示登录入口。
9. 同步账号遇到受控503，保留旧页草稿且维持请求隔离；重试核对成功后才切换。
10. 重载恢复遇到受控503时保留持久化凭证，重试后找回原云端旅行。
11. 身份核对不可用时允许主动登录；登录请求不附带尚未核对的旧凭证，新账号仍无法读取原旅行。

原生confirm由测试监听并实际接受/取消，没有替换window.confirm。协作等待实际8秒同步间隔，不调用组件内部函数。

每项使用全新浏览器上下文；跨标签用例在该上下文中打开第二个页面共享localStorage。全局清理先停止后端，再校验生成目录确属系统临时目录后删除；Playwright管理Vite与独立浏览器的退出。截图和失败trace保存在 `frontend/playwright-results/accounts`（Git忽略）。失败trace可能含合成密码和测试token，不能放入真实账号数据。

这是本机真实后端与合成账号证据；503是浏览器路由注入的故障，不是真实运营网络中断。不证明生产账号、实际手机设备、所有复杂跨标签切换、代理/HTTPS、多进程或真实供应商已验收。原有游客草稿套件独立运行：`npm run test:e2e:drafts`，输出 `playwright-results/drafts`。

## 跨标签处理约定

[storage事件](https://developer.mozilla.org/en-US/docs/Web/API/Window/storage_event)只能通知其他页面，不能取消另一页已经写入的凭证。本页因此保留已核对的账号凭证快照，并在每次请求前、响应解码后核对共享状态；变化时拒绝请求/迟到结果，不自动覆盖草稿，也不把本页旧退出动作写回新账号。

用户从提示条点击“同步账号”，经草稿确认后，只用新凭证请求身份核对；成功后才接受新身份。核对失败保留旧显示与草稿，普通请求继续暂停。启动时尚未核对的持久化凭证同样不能用于普通请求；游客无凭证请求不受此限制。已经发送的操作可能已在原账号下完成，页面明确说明，不能声称中断或撤回了后端操作。

用户主动提交的登录/注册另走无Authorization的认证请求，仍先检查草稿保护，并在返回时核对共享凭证和本页请求代次是否变化。身份核对服务暂时失败时，该入口仍可使用，成功登录后再接受返回的账号与新凭证。

`frontend/test/sessionToken.test.js`另有5项自动测试，覆盖未核对凭证、身份核对期间再次变化，以及实际JSON/照片/上传/流式入口的迟到响应隔离；这些照片/上传测试只使用内存fetch替身，没有上传文件。
