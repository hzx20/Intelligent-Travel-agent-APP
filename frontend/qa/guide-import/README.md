# 攻略图片导入隔离验收

frontend 下运行 `npm run test:e2e:guide-import`。只使用项目 `qa/photo-upload/sample.png`（32×32纯色、117字节），用户已明确授权发送至本机5264，经代理至18963。此授权不包括真实智谱上传或其他个人图片。

真实登录、SQLite、请求解码/像素校验、版本检查、地点匹配、云端/本机应用；仅OCR/模型传输由 guide-import-backend.py 合成。外部钥匙为空，非本机网络阻止，图片不保存。每例通过仅存在于测试夹具的控制接口重置游客限流窗口；生产限流代码不变，其限流证据来自后端专项。

五场景×桌面/手机共10项：账号及游客选图—识别—核对—正文—预览—确认应用；取消换图及重识别失败保留核对文字/同图重选；导入提交后丢响应只读核对不重发；未送达核对后原内容继续及坏OCR回执保护。使用真实文件选择、FileReader和本机HTTP，纯色图片只用于证明管道，合成识别文字不能证明真实OCR准确率。

端口5264/18963与accounts、workspace、guide-detail等共用，串行执行；临时库和进程由setup清理。截图/trace可能含合成凭证，不公开。最终证据、失败记录和下一步见 docs/交接归档-攻略图片导入恢复.md。
