## 页面覆盖

1. 正常生成一份历史，刷新仍读取；无地图时降级不影响结果。
2. 切到其他页面，后台继续，返回只接同次任务。
3. 追问已有片段时刷新，复用同一气泡，完整快照不重复拼接token。
4. 执行者中断后同编号恢复，reset清旧片段，历史只有一份。
5. 轮询503显示重连，读到已有结果，不再POST生成。
6. 停止先确认后台状态，取消持久化，刷新不恢复执行。
7. 取消已生效后丢响应，轮询仍找到取消结果。
8. 换号确认可取消；接受后新账号不见旧任务，切回原账号接回。
9. 游客按本标签编号刷新恢复；新标签没有active列表，不列其他游客任务。
10. 坏的200/错任务编号不更新界面，读到真回执才恢复。
11. 原账号历史删除已发后换号，迟到结果不在新账号弹错或显示撤销条。

## 行为边界

任务60秒租约，约20秒心跳；失去执行者后最多恢复一次，即最多执行两次，每次最多10分钟。恢复从原输入重新跑图，可能重复调用供应商产生费用；历史只保存一次不代表外部只调用一次。取消持久化先撤销令牌，外部已发请求不保证撤回；其他进程需等下一心跳或写入时停止。

完成/失败/取消任务按编号保留30分钟，过期调度清理，停机时物理删除延后；已保存AiPlan历史继续保留。游客临时任务也落库，但没有账号列表，编号等同不公开访问凭证。前端缓存按账号分开，游客仍是本标签匿名会话；清浏览器数据或关标签可能失去入口。

可靠创建后续模块现已补UUID、游客凭证、固定快照和cancel模式，本套已改用专用新路径；新增30项见`../plan-creation/README.md`，无标识旧/jobs及SSE仍不保证创建去重。规划历史保护另有32项，见`../plan-history/README.md`；本套删除迟到场景已改用带版本的content路径，并明确接受换号前的未确认操作提示。plan-history也共用5264/18963，须串行。真实模型重启、生产迁移、共享限流/酒店地图缓存和实际设备仍在原整体待办中。`--workers 1`默认未改，任务表独占证据不是整个应用已经完成多进程部署。
